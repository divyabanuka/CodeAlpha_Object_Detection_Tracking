# CodeAlpha Object Detection and Tracking

Real-time object detection and tracking using Python, OpenCV, and YOLO.

## 🚀 Live Demo

The application is deployed using Streamlit Community Cloud.
[Open Live Demo](https://codealphaobjectdetectiontracking-hlwb5kh8jgud8vdpfscukp.streamlit.app/)

## ✨ Features

- Real-time object detection
- Object tracking with unique IDs
- YOLO-based detection
- Live webcam support
- Streamlit web interface

## 🛠️ Technologies Used

- Python
- OpenCV
- YOLO
- Ultralytics
- Streamlit
- Streamlit-WebRTC

## 📂 Project Files

- `app.py` – Original OpenCV detection and tracking application
- `streamlit_app.py` – Streamlit web application
- `web_app.py` – Gradio version
- `yolo11n.pt` – YOLO model
- `requirements.txt` – Required Python packages
