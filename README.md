# 🎯 CodeAlpha Object Detection & Tracking

A computer vision project developed as part of the CodeAlpha internship.

This project uses YOLO (You Only Look Once) to detect objects in images and track objects in uploaded videos.

## 🚀 Features

- 🖼️ Object detection in images
- 🎥 Video object detection
- 🎯 Object tracking using ByteTrack
- 📦 YOLO11n pretrained model
- ☁️ Deployed using Streamlit Community Cloud
- 📥 Download processed tracking videos

## 🛠️ Technologies Used

- Python
- YOLO / Ultralytics
- OpenCV
- Streamlit
- Pillow
- ByteTrack

## ▶️ How to Run

Install the required dependencies:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run streamlit_app.py
